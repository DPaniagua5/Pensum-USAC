# Pensum Interactivo USAC

Bienvenido a la documentación del **Pensum Interactivo** para la carrera de Ingeniería en Ciencias y Sistemas de la USAC.

## ¿Qué es esto?

Una herramienta web que te permite:

- **Visualizar tu pensum** y el progreso de cada curso
- **Planificar tus semestres** según tu promedio de zona
- **Escanear tu hoja de notas** en PDF para marcar cursos automáticamente
- **Armar tu horario** con los cursos disponibles cada periodo

## Acceso rápido

| Módulo | Descripción |
| :--------: | :-------------: |
| [Pensum](pensum.md) | Visualización y marcado de cursos |
| [Planificador](planificador.md) | Organización por semestres |
| [Escanear Notas](scanner.md) | Importar notas desde PDF |
| [Horario](horario.md) | Constructor de horario semanal |

## Pensums disponibles

Actualmente la aplicación soporta los 3 pensums activos para Ingeniería en ciencias y sistemas:

- **Antiguo** — 250 créditos
- **2022** — 300 créditos  
- **2025** — 300 créditos

> 💡 Puedes cambiar entre pensums desde el selector en el header. El progreso de cada uno se guarda de forma independiente.
